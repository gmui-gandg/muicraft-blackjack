# Rules and controls

For entertainment only — virtual chips, no cash value

Local balances are editable by the player and are not verified scores.

## classic-six-deck-s17-v1

- Six standard 52-card decks (312 cards). Shuffle at start and before a new round
  when 78 or fewer cards remain; never intentionally reshuffle mid-round.
- Dealer hits through 16 and stands on all 17, including soft 17 (S17).
  An Ace or ten-value upcard triggers an opening peek for natural blackjack,
  before normal player actions.
- Number cards count at face value; J/Q/K count 10. Ace counts as 11 when safe,
  otherwise 1. An unsplit opening Ace plus ten-value card is natural blackjack,
  paying 3:2. Both opening naturals push; dealer-only natural loses.
- Ordinary wins pay 1:1; losses forfeit the stake; equal non-bust totals push
  and return the stake. Reaching 21 or bust automatically ends that hand.
- One funded split of two identical ranks creates at most two hands. Q + Q
  qualifies; 10 + J does not. No resplit. Split aces receive exactly one card
  each then automatically stand. Split 21 pays ordinary 1:1, never natural 3:2.
- Funded first-two-card doubles are allowed, including non-ace split hands.
  Commit an equal additional stake, receive exactly one card, then automatically
  stand. Each split hand settles independently.
- Starting bankroll: 1,000 virtual chips. Wagers: 10–500 in multiples of 10,
  capped by available balance. Presets add 10, 50 or 100 chips.
  No insurance, surrender or side bets.
- Next Hand is explicit. Below the minimum wager, Reset Virtual Bankroll requires
  confirmation. Cancel leaves funds unchanged.

## Keyboard and preferences

H: Hit; S: Stand; D: Double; P: Split. Each requires engine eligibility.
Enter on neutral page focus invokes the current primary: Deal while betting,
Hit during player play, Next Hand after settlement. Enter on a focused button
activates that button instead. Selects and editable fields retain native keys.
Shortcuts ignore held/repeated, modified and composing key events, and pause
inside Help or reset confirmation. Release a key before using it again.

Tab to Help and activate with Enter or Space. Close Help receives focus.
Tab/Shift+Tab stay there; Escape or Close Help closes and restores opener focus.
Motion is a keyboard-operable saved selection: system, reduced or full.
Audio remains muted.

Reload restores only settled bankroll and versioned preferences. Unfinished rounds
are discarded with an explanation. Use one active session per browser storage key;
concurrent tabs can overwrite progress. These are local virtual chips with no
purchases, transfers, redemption or cash value.
